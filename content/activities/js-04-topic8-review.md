> - Form groups of 3-4 students
> - Assign a notetaker (someone to write down key points)
> - Assign someone to share out to the larger group at the end
> - Answer the "General Reflection" questions (5 minutes)
> - Answer your group's assigned questions (10 minutes)
> - Prepare a brief share-out (5 minutes)

## General Reflections (Everyone)

Before diving into specific topics, discuss these questions as a group:

1. What JavaScript concepts from Topic 8 do you feel most confident about? Which ones are still unclear?
2. How does JavaScript differ from Java in terms of syntax and programming patterns? What similarities did you notice?
3. What was the most challenging part of working with the DOM (Document Object Model)? What strategies helped you succeed?

## DOM Manipulation

### Discussion Questions

1. **Selecting Elements:**
   - What's the difference between `document.querySelector()` and `document.querySelectorAll()`?
   - When would you use `getElementById()` vs `querySelector('#id')`?
   - How do you select elements by class, tag name, or other attributes?

2. **Modifying Content:**
   - What's the difference between `textContent` and `innerHTML`?
   - When would you use each one?
   - What are the security implications of using `innerHTML`?

3. **Event Handling:**
   - How do you attach an event listener to an element?
   - What's the difference between inline event handlers (in HTML) and using `addEventListener()`?
   - Why do you think that the `addEventListener()` technique is generally preferred?

## Java vs JavaScript Comparison

### Discussion Questions

1. **Variable Declarations:**
   - How do variable declarations differ between Java and JavaScript?
   - What's the difference between `let`, `const`, and `var` in JavaScript?
   - In Java, you specify types (`int`, `String`). How does JavaScript handle types?

2. **Arrays and Objects:**
   - How are arrays different in JavaScript compared to Java?
   - What are JavaScript objects, and how do they compare to Java classes/objects?
   - Can you access object properties in JavaScript the same way as in Java?

3. **Functions as First-Class Citizens:**
   - In JavaScript, functions can be stored in variables, passed as arguments, and returned from other functions. How is this different from Java?
   - What does it mean that functions are "first-class citizens" in JavaScript?


### Share-Out Focus
Be ready to share the most significant difference between Java and JavaScript that your group identified, and why it matters.

## General Concepts

### Discussion Questions

1. **Code Organization:**
   - How do you organize JavaScript code in a web page?
   - Where should you put your JavaScript code (in the HTML file, in a separate file)?
   - What's the difference between inline scripts and external script files?

2. **Debugging Strategies:**
   - What tools do you use to debug JavaScript (console.log, browser DevTools)?
   - How do you find errors in your JavaScript code?
   - What's a common mistake you've made, and how did you fix it?

3. **Best Practices:**
   - What naming conventions should you follow for JavaScript variables and functions?
   - How do you write readable, maintainable JavaScript code?
   - What are some common "gotchas" or pitfalls to avoid?

4. **Whiteboard Prompt:**
   - Design a simple interactive web page:
     - Draw the HTML structure (what elements you'd need)
     - List the JavaScript functions you'd write
     - Show how the functions would interact with the DOM
     - Indicate where event listeners would be attached

### Share-Out Focus
Be ready to share one best practice or debugging tip that your group found most helpful.

## Share-Out (5 minutes)

Each group will have 1-2 minutes to share their key insights with the class. Focus on:
- One main takeaway from your discussion
- One question or concept that's still unclear
- One tip or strategy that might help other students

- Selecting and modifying DOM elements
- Understanding how JavaScript differs from Java
