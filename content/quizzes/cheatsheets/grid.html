CSS Grid Cheatsheet

CSS Grid is a two-dimensional layout system that allows you to create complex layouts with rows and columns. It provides precise control over both horizontal and vertical alignment of items.

Container Properties

Property Examples Notes
display
  • display: grid;
  • Makes the element a grid container
  • Required for all CSS Grid layouts
grid-template-columns
  • grid-template-columns: 1fr 200px auto;
  • grid-template-columns: repeat(3, 1fr);
  • Defines how many columns the grid has and their sizes
  • 1fr: Fractional unit (flexible, takes equal share)
  • repeat(3, 1fr): Shorthand for 3 equal columns
  • 200px 1fr: Fixed width + flexible column
grid-template-rows
  • grid-template-rows: 100px 200px 100px;
  • grid-template-rows: 1fr 2fr;
  • Defines how many rows the grid has and their heights
  • Each value represents the height of one row
gap
  • gap: 15px;
  • gap: 20px;
  • Adds consistent spacing between grid items
  • Can also use row-gap and column-gap separately

Child/Item Properties

Property Examples Notes
grid-column-start
  • grid-column-start: 1;
  • grid-column-start: 2;
  • grid-column-start: span 2;
  • Defines where an item starts in the column grid
  • Numeric value: Starts at that column line
  • span 2: Item spans 2 columns from its starting position
grid-column-end
  • grid-column-end: 3;
  • grid-column-end: 4;
  • Defines where an item ends in the column grid
  • Numeric value: Ends at that column line
  • Used with grid-column-start to define column span
grid-row-start
  • grid-row-start: 1;
  • grid-row-start: 2;
  • grid-row-start: span 2;
  • Defines where an item starts in the row grid
  • Numeric value: Starts at that row line
  • span 2: Item spans 2 rows from its starting position
grid-row-end
  • grid-row-end: 3;
  • grid-row-end: 4;
  • Defines where an item ends in the row grid
  • Numeric value: Ends at that row line
  • Used with grid-row-start to define row span
grid-column
  • grid-column: span 2;
  • grid-column: 1 / 3;
  • Controls which columns an item spans
  • span 2: Item spans across 2 columns
  • 1 / 3: Item starts at column 1, ends at column 3 (spans 2 columns)
grid-row
  • grid-row: span 2;
  • grid-row: 1 / 3;
  • Controls which rows an item spans
  • span 2: Item spans across 2 rows
  • 1 / 3: Item starts at row 1, ends at row 3 (spans 2 rows)
