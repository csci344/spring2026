DOM Event Handlers & Functions Cheatsheet

Learn how to create functions and attach event listeners to make interactive web pages.

Creating the runCode() Function

Pattern Example Notes
function runCode()
  • function runCode() {
      // your code here
    }
  • Define the function that will be called by the Run button
  • The HTML button has onclick="runCode()"

Adding Event Listeners

Method Examples Notes
addEventListener
  • button.addEventListener('click', function() {
      // code here
    });
  • button.addEventListener('click', () => {
      // code here
    });
  • Attaches an event handler to an element
  • First argument: event type (string)
  • Second argument: function to run when event occurs
querySelector + addEventListener
  • const btn = document.querySelector('#myBtn');
    btn.addEventListener('click', function() {
      // code here
    });
  • First select the element, then add the listener
  • Use inside runCode() to set up event handlers

Common Event Types

Event Type Example When It Fires
'click'
  • button.addEventListener('click', function() { });
  • When user clicks a button or element
'submit'
  • form.addEventListener('submit', function(e) {
      e.preventDefault();
    });
  • When a form is submitted
  • Usually need e.preventDefault() to stop page reload

Preventing Default Behavior

Method Example Notes
preventDefault()
  • form.addEventListener('submit', function(e) {
      e.preventDefault();
      // your code here
    });
  • Stops the browser's default action (like form submission)
  • Call on the event object (usually named e or event)
  • Must be inside the event handler function

Reading Input Values

Property Example Notes
input.value
  • const input = document.querySelector('#nameInput');
    const text = input.value;
  • output.textContent = input.value;
  • Gets the current value from an input field
  • Use inside event handler to read what user typed

Complete Examples

Task Solution Notes
Click to toggle class
  • function runCode() {
      const btn = document.querySelector('#toggleBtn');
      const panel = document.querySelector('#panel');
      btn.addEventListener('click', function() {
        panel.classList.toggle('open');
      });
    }
  • Set up listener inside runCode()
  • Toggle class when button is clicked
Click to copy input to output
  • function runCode() {
      const btn = document.querySelector('#addBtn');
      const input = document.querySelector('#nameInput');
      const output = document.querySelector('#output');
      btn.addEventListener('click', function() {
        output.textContent = input.value;
      });
    }
  • Read input.value
  • Set output.textContent
Form submit with preventDefault
  • function runCode() {
      const form = document.querySelector('#myForm');
      const status = document.querySelector('#status');
      form.addEventListener('submit', function(e) {
        e.preventDefault();
        status.textContent = 'Submitted';
      });
    }
  • Event handler receives event object as parameter
  • Call e.preventDefault() first
  • Then do your DOM updates
Toggle with conditional text
  • function runCode() {
      const btn = document.querySelector('#toggleBtn');
      const panel = document.querySelector('#panel');
      btn.addEventListener('click', function() {
        panel.classList.toggle('open');
        if (panel.classList.contains('open')) {
          btn.textContent = 'Close';
        } else {
          btn.textContent = 'Open';
        }
      });
    }
  • Toggle the class first
  • Check with classList.contains()
  • Update button text based on state
Click to change image src
  • function runCode() {
      const btn = document.querySelector('#swapBtn');
      const img = document.querySelector('#pic');
      btn.addEventListener('click', function() {
        img.src = 'cat.jpg';
      });
    }
  • Set img.src to change the image
  • Can use full path or relative path

Key Patterns

  • Always define runCode() function - This is called by the Run button
  • Select elements first - Use querySelector() to get elements
  • Add listeners inside runCode() - Set up event handlers when function runs
  • Read values when event fires - Access input.value inside the event handler
  • Use preventDefault() for forms - Stop default form submission behavior
