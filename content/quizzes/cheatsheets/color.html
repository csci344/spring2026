CSS Color Cheatsheet

CSS provides multiple ways to specify colors for text, backgrounds, and borders. You can use color names, hexadecimal values, RGB, or RGBA formats.

Property Examples Notes
color
  • color: blue;
  • color: #333333;
  • color: rgb(255, 0, 0);
  • Sets the text color
  • Can use color names, hex, RGB, or RGBA
background-color
  • background-color: white;
  • background-color: #ffffff;
  • background-color: rgba(0, 0, 0, 0.5);
  • Sets the background color of an element
  • Can use color names, hex, RGB, or RGBA
border-color
  • border-color: red;
  • border-color: #ccc;
  • Sets the border color
  • Can also be set in the border shorthand property
Color Formats
  • color: red;
  • color: #ff0000;
  • color: rgb(255, 0, 0);
  • color: rgba(255, 0, 0, 0.5);
  • Color names: red, blue, white, etc.
  • Hexadecimal: #ff0000 (red), #000000 (black), #ffffff (white)
  • RGB: rgb(red, green, blue) where values are 0-255
  • RGBA: adds alpha (transparency) 0-1 (0 = transparent, 1 = opaque)
