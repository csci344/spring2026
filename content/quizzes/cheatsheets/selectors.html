CSS Selectors Cheatsheet

CSS selectors are patterns used to select and style HTML elements. They allow you to target specific elements, classes, IDs, or element relationships to apply styles.

Selector Type Examples Notes
Tag/Element
  • p { color: blue; }
  • h1 { font-size: 2em; }
  • div { margin: 10px; }
  • Selects all elements of a specific type
  • Uses the HTML element name directly
Class
  • .highlight { background-color: yellow; }
  • Selects all elements with a specific class attribute
  • Starts with a period (.)
ID
  • #main-title { font-size: 32px; }
  • Selects the element with a specific ID attribute
  • Starts with a hash (#)
  • IDs should be unique on a page
Descendant
  • div p { font-style: italic; }
  • Selects elements that are descendants (at any nesting level)
  • Uses a space between selectors
Direct Child
  • ul.menu > li { border: 1px solid hotpink; }
  • Selects only direct children (not grandchildren)
  • Uses the > symbol
Grouping
  • h1, h2, h3 { color: red; }
  • Applies the same styles to multiple selectors
  • Uses a comma to separate selectors
Universal
  • * { margin: 0; padding: 0; }
  • Selects all elements on the page
  • Useful for resetting styles or applying global rules
Multiple Classes
  • .red.blue { color: purple; }
  • Selects elements that have both classes (no space between)
  • Chain class selectors together without spaces
Element + Class
  • td.dark { background-color: #333; }
  • Selects specific elements that have a class
  • Combine element name with class (no space)
