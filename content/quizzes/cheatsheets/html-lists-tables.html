HTML Lists & Tables Cheatsheet

HTML provides tags for creating organized lists and structured tables to display data in rows and columns.

Tag Examples Notes
<ul>
  • <ul><li>Item</li></ul>
  • Unordered list (bulleted list)
  • Contains <li> items
<ol>
  • <ol><li>First</li></ol>
  • Ordered list (numbered list)
  • Contains <li> items
<li>
  • <li>List item</li>
  • List item (used inside <ul> or <ol>)
<table>
  • <table><tr><td>Cell</td></tr></table>
  • Creates a table
  • Contains <tr> (rows) and <td> or <th> (cells)
<tr>
  • <tr><td>Cell 1</td><td>Cell 2</td></tr>
  • Table row
  • Contains <td> or <th> cells
<td>
  • <td>Table cell</td>
  • Table data cell (regular cell)
<th>
  • <th>Header</th>
  • Table header cell (bold, centered by default)
  • Used in first row for column headers
