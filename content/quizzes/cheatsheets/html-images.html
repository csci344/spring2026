HTML Images Cheatsheet

The <img> tag embeds images into web pages. Always include descriptive alt text for accessibility.

Tag/Attribute Examples Notes
<img>
  • <img src="photo.jpg" alt="Description">
  • Self-closing tag for embedding images
  • Requires src and alt attributes
src
  • src="image.jpg"
  • src="../images/photo.png"
  • src="https://example.com/image.jpg"
  • Required: specifies image file path or URL
  • Can be relative or absolute path
alt
  • alt="A red bicycle"
  • alt="Company logo"
  • Required: alternative text for accessibility
  • Shown if image fails to load
  • Used by screen readers
width / height
  • width="300"
  • height="200"
  • Optional: sets image dimensions in pixels
  • Better to use CSS for sizing
