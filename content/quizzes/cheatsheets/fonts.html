CSS Text & Fonts Cheatsheet

CSS provides extensive control over text appearance, including font family, size, weight, style, alignment, and spacing properties.

Property Examples Notes
font-family
  • font-family: "Times New Roman", Times, serif;
  • font-family: Arial, sans-serif;
  • Specifies the font family (typeface)
  • Provide fallbacks separated by commas
  • Fonts with spaces should be in quotes
font-size
  • font-size: 16px;
  • font-size: 1.1em;
  • font-size: 1.2rem;
  • Sets the font size
  • Use em or rem for responsive design
font-weight
  • font-weight: bold;
  • font-weight: 700;
  • font-weight: normal;
  • Controls text thickness (boldness)
  • Values: normal, bold, or numeric (100-900)
font-style
  • font-style: italic;
  • font-style: normal;
  • Controls text style
  • Values: normal, italic, oblique
text-align
  • text-align: left;
  • text-align: center;
  • text-align: right;
  • text-align: justify;
  • Controls horizontal text alignment
  • Default is left
letter-spacing
  • letter-spacing: 1.5em;
  • letter-spacing: 2px;
  • Controls space between letters
line-height
  • line-height: 120%;
  • line-height: 1.5;
  • Controls space between lines of text
word-spacing
  • word-spacing: 5px;
  • Controls space between words
