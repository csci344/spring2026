Learn how to modify text content, insert HTML, and create new elements in the DOM.

Selecting Elements

Method Examples Notes
querySelector
  • const message = document.querySelector('#message');
  • const list = document.querySelector('#list');
  • Selects a single element by CSS selector
  • Use #id for IDs

Text Content vs HTML

Property Examples Notes
textContent
  • element.textContent = 'Hello';
  • element.textContent = '<strong>Hello</strong>';
  • Sets plain text (HTML is escaped)
  • Angle brackets appear as text, not HTML
  • Use when you want to display HTML tags as text
innerHTML
  • element.innerHTML = '<strong>Hello</strong>';
  • element.innerHTML = '<p>Done</p>';
  • Sets HTML content (parsed as HTML)
  • HTML tags are rendered, not shown as text
  • Use when you want to insert actual HTML elements
  • ⚠️ Be careful with user input (security risk)

Inserting HTML

Method Examples Notes
insertAdjacentHTML
  • element.insertAdjacentHTML('beforeend', '<li>Third</li>');
  • element.insertAdjacentHTML('beforebegin', '<p>Note</p>');
  • Inserts HTML at a specific position
  • First param: position ('beforebegin', 'afterbegin', 'beforeend', 'afterend')
  • Second param: HTML string
  • Doesn't replace existing content
Position values
  • 'beforebegin' - Before the element
  • 'afterbegin' - Inside, at the start
  • 'beforeend' - Inside, at the end (append)
  • 'afterend' - After the element
  • Most common: 'beforeend' to append
  • Use 'beforebegin' to insert before

Creating New Elements

Method Examples Notes
createElement
  • const btn = document.createElement('button');
  • const li = document.createElement('li');
  • Creates a new element (not yet on page)
  • Pass tag name as string
appendChild
  • container.appendChild(btn);
  • list.appendChild(li);
  • Adds element as last child of parent
  • Element must be created first
Setting properties
  • btn.id = 'newBtn';
  • btn.textContent = 'Click me';
  • li.textContent = 'Item';
  • Set properties before or after appending
  • Use id for ID attribute
  • Use textContent for text

Removing Elements

Method Examples Notes
remove()
  • element.remove();
  • const toRemove = document.querySelector('#toRemove');
    toRemove.remove();
  • Removes element from the page
  • Simplest method

Complete Examples

Task Solution Notes
Set innerHTML
  • function runCode() {
      const msg = document.querySelector('#message');
      msg.innerHTML = '<strong>Hello</strong>';
    }
  • HTML is parsed and rendered
Set textContent
  • function runCode() {
      const msg = document.querySelector('#message');
      msg.textContent = '<strong>Hello</strong>';
    }
  • Shows angle brackets as text
Append with insertAdjacentHTML
  • function runCode() {
      const list = document.querySelector('#list');
      list.insertAdjacentHTML('beforeend', '<li>Third</li>');
    }
  • 'beforeend' appends to the end
Insert before with insertAdjacentHTML
  • function runCode() {
      const target = document.querySelector('#target');
      target.insertAdjacentHTML('beforebegin', '<p id="note">Note</p>');
    }
  • 'beforebegin' inserts before the element
Create and append element
  • function runCode() {
      const container = document.querySelector('#container');
      const btn = document.createElement('button');
      btn.id = 'newBtn';
      btn.textContent = 'Click me';
      container.appendChild(btn);
    }
  • Create, configure, then append
Remove element
  • function runCode() {
      const toRemove = document.querySelector('#toRemove');
      toRemove.remove();
    }
  • Simple one-line removal
Replace all content
  • function runCode() {
      const container = document.querySelector('#container');
      container.innerHTML = '<p>Done</p>';
    }
  • Replaces all existing content

Key Patterns

  • Always define runCode() function - This is called by the Run button
  • Select elements first - Use querySelector() to get elements
  • Use textContent for plain text - HTML is escaped, shows as text
  • Use innerHTML for HTML - HTML is parsed and rendered
  • Use insertAdjacentHTML to add without replacing - Appends or inserts at specific position
  • Create elements with createElement - Then set properties and append
