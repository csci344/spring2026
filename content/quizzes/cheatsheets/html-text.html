HTML Text Markup Cheatsheet

HTML provides tags for structuring and formatting text content. These tags help organize content and provide meaning to different parts of your text.

Tag Examples Notes
<p>
  • <p>This is a paragraph.</p>
  • Defines a paragraph
  • Block-level element
<h1> to <h6>
  • <h1>Main Heading</h1>
  • <h2>Subheading</h2>
  • Heading tags (h1 = most important, h6 = least important)
  • Used for document structure and SEO
<strong>
  • <strong>Important text</strong>
  • Makes text bold and indicates importance
  • Semantic meaning: strong importance
<em>
  • <em>Emphasized text</em>
  • Makes text italic and indicates emphasis
  • Semantic meaning: emphasized text
<br>
  • Line 1<br>Line 2
  • Line break (self-closing tag)
  • Creates a new line within text
<hr>
  • <hr>
  • Horizontal rule (self-closing tag)
  • Creates a thematic break/divider
