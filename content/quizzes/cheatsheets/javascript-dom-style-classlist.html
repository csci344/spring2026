DOM Style Properties & classList Cheatsheet

Learn how to manipulate CSS styles, classes, and element properties using JavaScript.

Creating the runCode() Function

Pattern Example Notes
function runCode()
  • function runCode() {
      // your code here
    }
  • Define the function that will be called by the Run button
  • The HTML button has onclick="runCode()"

Selecting Elements

Method Examples Notes
querySelector
  • const box = document.querySelector('#box');
  • const btn = document.querySelector('#btn');
  • Selects a single element by CSS selector
  • Use #id for IDs, .class for classes
querySelectorAll
  • const items = document.querySelectorAll('#list li');
  • for (const item of items) {
      item.classList.add('active');
    }
  • Selects all matching elements
  • Returns a NodeList (array-like)
  • Use a loop to modify each element

Working with Classes

Method/Property Examples Notes
classList.add()
  • element.classList.add('active');
  • box.classList.add('highlight', 'bold');
  • Adds one or more classes to an element
  • Doesn't remove existing classes
classList.remove()
  • element.classList.remove('disabled');
  • btn.classList.remove('hidden', 'inactive');
  • Removes one or more classes from an element
classList.toggle()
  • element.classList.toggle('open');
  • element.classList.toggle('active', true);
  • Adds class if missing, removes if present
  • Second parameter (true/false) forces add/remove
classList.contains()
  • if (box.classList.contains('active')) {
      // do something
    }
  • Returns true if element has the class, false otherwise
  • Useful for conditional logic
className
  • element.className = 'card featured';
  • card.className = 'card';
  • Sets all classes at once (replaces existing)
  • Use space-separated string for multiple classes
  • Prefer classList for adding/removing individual classes

Working with Styles

Property Examples Notes
style.backgroundColor
  • box.style.backgroundColor = 'red';
  • box.style.backgroundColor = 'rgb(255, 0, 0)';
  • box.style.backgroundColor = ''; // clear
  • Use camelCase: backgroundColor not background-color
  • Set to empty string to clear the style
style.borderWidth
  • box.style.borderWidth = '4px';
  • Always include units (px, em, etc.)
style.borderColor
  • box.style.borderColor = 'blue';
  • box.style.borderColor = '#0000ff';
  • Use color names, hex codes, or rgb()
style.borderStyle
  • box.style.borderStyle = 'solid';
  • Common values: 'solid', 'dashed', 'dotted', 'none'
style.display
  • box.style.display = 'none'; // hide
  • box.style.display = 'block'; // show
  • 'none' removes element from layout
  • Element takes up no space when hidden
style.visibility
  • box.style.visibility = 'hidden'; // hide
  • box.style.visibility = 'visible'; // show
  • 'hidden' hides element but keeps space
  • Element still takes up space in layout

Working with Attributes

Method/Property Examples Notes
dataset
  • element.dataset.status = 'ready';
  • // Sets data-status="ready"
  • Accesses data-* attributes
  • Converts kebab-case to camelCase
  • data-status → dataset.status
setAttribute()
  • btn.setAttribute('aria-label', 'Close');
  • img.setAttribute('src', 'image.jpg');
  • Sets any attribute on an element
  • First param: attribute name
  • Second param: attribute value
src (direct property)
  • img.src = 'bird.jpg';
  • img.src = 'images/cat.jpg';
  • For images, can set src directly
  • Same as setAttribute('src', ...)

Complete Examples

Task Solution Notes
Add class
  • function runCode() {
      const box = document.querySelector('#box');
      box.classList.add('active');
    }
  • Select element, then add class
Set className
  • function runCode() {
      const card = document.querySelector('#card');
      card.className = 'card featured';
    }
  • Replaces all classes with new value
Set style property
  • function runCode() {
      const box = document.querySelector('#box');
      box.style.backgroundColor = 'red';
    }
  • Use camelCase for CSS properties
Add class to multiple elements
  • function runCode() {
      const items = document.querySelectorAll('#list li');
      for (const item of items) {
        item.classList.add('item');
      }
    }
  • Use querySelectorAll and loop
Conditional based on class
  • function runCode() {
      const box = document.querySelector('#box');
      const status = document.querySelector('#status');
      if (box.classList.contains('active')) {
        status.textContent = 'ON';
      } else {
        status.textContent = 'OFF';
      }
    }
  • Check class with contains()
  • Use if/else for conditional logic

Key Patterns

  • Always define runCode() function - This is called by the Run button
  • Select elements first - Use querySelector() or querySelectorAll()
  • Use camelCase for style properties - backgroundColor not background-color
  • Use classList for individual classes - Better than className for add/remove
  • Use className to set all classes - When you need to replace all classes at once
