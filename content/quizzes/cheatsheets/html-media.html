HTML Media Tags Cheatsheet

HTML5 provides tags for embedding audio, video, and other external content into web pages.

Tag Examples Notes
<audio>
  • <audio src="sound.mp3" controls></audio>
  • Embeds audio files
  • controls attribute adds play/pause controls
  • Supports multiple formats (mp3, ogg, wav)
<video>
  • <video src="movie.mp4" controls></video>
  • Embeds video files
  • controls attribute adds play/pause controls
  • Supports multiple formats (mp4, webm, ogg)
<iframe>
  • <iframe src="https://example.com"></iframe>
  • Embeds another web page within current page
  • Commonly used for videos, maps, external content
  • Requires src attribute with URL
