HTML Hyperlinks Cheatsheet

Hyperlinks connect web pages together. The anchor tag (<a>) is used to create links to other pages, files, or sections within the same page.

Tag/Attribute Examples Notes
<a>
  • <a href="page.html">Link Text</a>
  • Anchor tag for creating hyperlinks
  • Requires href attribute
href
  • href="contact.html"
  • href="https://example.com"
  • href="#section"
  • Specifies the link destination
  • Can be relative path, absolute URL, or anchor (#id)
target
  • target="_blank"
  • target="_self"
  • _blank: opens in new tab/window
  • _self: opens in same window (default)
Path Types
  • href="page.html"
  • href="../folder/page.html"
  • href="/root/page.html"
  • Same directory: just filename
  • Parent directory: ../folder/file
  • Root-relative: /folder/file (from site root)
