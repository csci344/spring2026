CSS Box Model Cheatsheet

The box model describes how every HTML element is a rectangular box with content, padding, border, and margin. Understanding these properties is essential for layout and spacing.

Property Examples Notes
margin
  • margin: 10px;
  • margin: 10px 20px;
  • margin-top: 10px;
  • Space OUTSIDE the element, between elements
  • Can be set for all sides or individually (top, right, bottom, left)
padding
  • padding: 10px;
  • padding: 10px 20px;
  • padding-top: 10px;
  • Space INSIDE the element, between content and border
  • Can be set for all sides or individually (top, right, bottom, left)
border
  • border: 1px solid #ccc;
  • border: dotted 1px #ccc;
  • border-top: 2px solid red;
  • Border around the element (between padding and margin)
  • Syntax: style width color (e.g., solid 1px #ccc)
box-sizing
  • box-sizing: border-box;
  • box-sizing: content-box;
  • border-box: padding and border included in width/height (recommended)
  • content-box: padding and border added to width/height (default)
