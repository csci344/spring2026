HTML Forms Cheatsheet

HTML forms collect user input and submit data to a server. Forms contain various input elements like text fields, buttons, checkboxes, and dropdowns.

Tag/Attribute Examples Notes
<form>
  • <form action="/submit" method="post"></form>
  • Container for form elements
  • action: where form data is sent
  • method: get or post
<input>
  • <input type="text" name="username">
  • <input type="email" name="email">
  • <input type="password" name="pass">
  • Self-closing tag for various input types
  • type: text, email, password, checkbox, radio, etc.
  • name: identifies the input (required for submission)
<label>
  • <label for="username">Username:</label>
  • Label for form inputs (improves accessibility)
  • Use for attribute to link to input id
<textarea>
  • <textarea name="message" rows="4" cols="50"></textarea>
  • Multi-line text input
  • rows and cols set size
<select>
  • <select name="country"><option>USA</option></select>
  • Dropdown menu
  • Contains <option> elements
<button>
  • <button type="submit">Submit</button>
  • <button type="button">Click</button>
  • Button element
  • type="submit": submits the form
  • type="button": regular button (no form submission)
