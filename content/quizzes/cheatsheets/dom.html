JavaScript DOM Cheatsheet

The Document Object Model (DOM) allows JavaScript to interact with HTML elements. Use these methods to select elements, modify content, and handle events.

Method/Property Examples Notes
getElementById
  • document.getElementById('myId');
  • Selects an element by its id attribute
  • Returns a single element or null
querySelector
  • document.querySelector('#myId');
  • document.querySelector('.myClass');
  • Selects the first element matching a CSS selector
  • Returns a single element or null
querySelectorAll
  • document.querySelectorAll('.myClass');
  • Selects all elements matching a CSS selector
  • Returns a NodeList (array-like)
addEventListener
  • element.addEventListener('click', function() { });
  • button.addEventListener('click', () => { });
  • Attaches an event handler to an element
  • Common events: 'click', 'input', 'change'
createElement
  • document.createElement('div');
  • document.createElement('li');
  • Creates a new HTML element
  • Returns the element (not yet added to page)
appendChild
  • parent.appendChild(newElement);
  • Adds an element as the last child of a parent
textContent
  • element.textContent = 'Hello';
  • let text = element.textContent;
  • Gets or sets the text content of an element
style
  • element.style.backgroundColor = 'blue';
  • element.style.display = 'none';
  • Modifies CSS styles of an element
  • Use camelCase for property names (backgroundColor, not background-color)
value
  • input.value = 'text';
  • let val = input.value;
  • Gets or sets the value of form inputs (input, textarea, select)
