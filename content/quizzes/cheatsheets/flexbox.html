Flexbox Cheatsheet

Property Values Notes
display flex
  • Makes the element a flex container
  • Required for all flexbox layouts
  • Example: display: flex;
flex-direction row column
  • row (default): Items flow horizontally
  • column: Items flow vertically
  • Example: flex-direction: row;
justify-content center space-between space-around flex-start flex-end
  • Controls alignment along the main axis (horizontal for row, vertical for column)
  • center: Centers items
  • space-between: Equal space between items, no space at edges
  • Example: justify-content: center;
align-items center flex-start flex-end stretch
  • Controls alignment along the cross axis (vertical for row, horizontal for column)
  • center: Centers items
  • stretch: Stretch to fill (default)
  • Example: align-items: center;
flex-wrap wrap nowrap
  • wrap: Allows items to wrap to next line when they don't fit
  • nowrap (default): Items stay on one line
  • Example: flex-wrap: wrap;
gap 20px (or any length)
  • Adds consistent spacing between flex items
  • Cleaner than using margins on individual items
  • Example: gap: 20px;
