CSS Media Queries Cheatsheet

Media queries allow you to apply different CSS styles based on screen size, device type, or other conditions. This is how you create responsive designs that work on phones, tablets, and desktops.

Property/Feature Examples Notes
@media
  • @media (min-width: 768px) { }
  • @media (max-width: 767px) { }
  • Basic media query syntax
  • min-width: applies when screen is at least this wide
  • max-width: applies when screen is this wide or smaller
Common Breakpoints
  • @media (min-width: 768px) { }
  • @media (min-width: 1024px) { }
  • 768px: tablet devices
  • 1024px: desktop devices
  • Mobile-first: start with mobile styles, add larger screen styles with min-width
