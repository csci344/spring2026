CSS Units Cheatsheet

CSS units determine how sizes are calculated. Absolute units are fixed, while relative units scale based on parent elements or viewport size. Use relative units for responsive design.

Unit Examples Notes
px
  • width: 100px;
  • font-size: 16px;
  • Absolute unit: fixed size (pixels)
  • Does not scale with parent or viewport
em
  • font-size: 1.5em;
  • margin: 2em;
  • Relative unit: relative to parent element's font-size
  • 1.5em = 1.5 × parent's font-size
rem
  • font-size: 1.2rem;
  • padding: 1rem;
  • Relative unit: relative to root element's font-size (usually <html>)
  • More predictable than em (not affected by parent)
%
  • width: 100%;
  • height: 50%;
  • Relative unit: relative to parent element
  • 100% = 100% of parent's width/height
vw
  • width: 50vw;
  • font-size: 5vw;
  • Viewport width: 1% of browser window width
  • 50vw = 50% of viewport width
vh
  • height: 100vh;
  • min-height: 50vh;
  • Viewport height: 1% of browser window height
  • 100vh = full viewport height
fr
  • grid-template-columns: 1fr 2fr;
  • grid-template-rows: 1fr 1fr 1fr;
  • Fraction: used in CSS Grid for flexible sizing
  • Represents a fraction of available space
