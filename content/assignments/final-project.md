# SPA Design & Wireframing Assignment

**Goal:** Design (not build yet) a small single-page app (SPA) that you will implement later using your own REST API.

You will decide **what to build**, **how it works**, and **how it looks** before writing any code.

---

## Part 1 — Decide What You’re Building

Choose **one** starter project idea below, or propose something of similar scope.

### Starter Project Ideas (2–3 API Endpoints)

- Live Music Memory Map (concerts you’ve attended)
- Public Art Explorer (murals, sculptures, installations)
- Favorite Coffee Spots
- Daily Walks & Wanders
- Street Food Tracker
- Urban Sound Journal
- Community Bulletin Board
- Museum Visit Log
- Favorite Study Spots
- Climate Feel Log (subjective weather)

### UI Criteria (All Apps Must Have)

Your app must include:
- **A list** of items (entries, places, events, etc.)
- **A map** showing item locations
- **A chart** summarizing the data (counts, categories, trends)

Constraints:
- Single-page app (no routing required)
- One primary user action
- 2–3 REST endpoints total
- No authentication
- Scope should feel *small and focused*

**Deliverable:**  
A 3–5 sentence description of your app and its primary user goal.

---

## Part 2 — Wireframing

Create wireframes for **2–3 screens** using one of the following tools:
- Paper
- Figma
- Balsamiq
- Whimsical

### Wireframing Rules
- Grayscale only (no color)
- Boxes + text labels only
- Focus on layout, hierarchy, and flow — not styling

Each wireframe should clearly show:
- What the user sees first
- The primary action
- How the list, map, and chart relate

**Deliverable:**  
Annotated wireframes + a short explanation of your layout decisions.

---

## Part 3 — Interface Aesthetics

Now layer visual design on top of your wireframes.

### Design Focus
- Color palette (primary, secondary, neutral)
- Contrast and readability
- Spacing, alignment, and visual hierarchy
- Overall tone or “feel” of the app

Rules:
- Color must not be the only way information is conveyed
- Visual design should support usability, not distract from it

**Deliverable:**  
A styled mockup and a short design rationale explaining your choices.

---

## Final Submission Checklist

- App concept description
- Wireframes (2–3 screens)
- Visual design mockup
- Brief design rationale

You will implement this app later using a REST API.
