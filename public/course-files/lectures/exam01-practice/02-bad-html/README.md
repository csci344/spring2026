# Exercise 02 — What’s wrong with this code? (Bad HTML)

## Goal

The page renders, but the HTML is “bad” (invalid structure, poor semantics, and some accessibility issues).

Your job is to **fix the HTML** so it is valid and semantic.

## Rules

- You may edit **only** `index.html` (leave `styles.css` alone).
- Do **not** change the visible words/sentences (text content).
- You may rearrange elements, change tags, add missing attributes, and fix ids/labels.

## Checklist (what to fix)

- Fix invalid nesting (e.g., block elements inside `<p>`, `<a>` around block sections, etc.).
- Replace “div soup” with semantic structure where appropriate (`header`, `nav`, `main`, `section`, `footer`).
- Fix duplicate `id` values.
- Fix the form so labels are correctly associated with inputs (`label for` + `input id`).
- Add missing `alt` text for images.
- Ensure heading order makes sense (one `<h1>`, then `<h2>`s, etc.).

## Done when

- The HTML validates (no obvious structural errors).
- Clicking labels focuses the correct input.
- The page is easy to navigate with just headings/landmarks.
