# Exercise 05 — Create this layout (Mobile vs Desktop)

## Goal

Recreate the layout shown in:

- `target-mobile.svg` (small screens)
- `target-desktop.svg` (wide screens)

using **responsive CSS**.

## Rules

- Do **not** edit `index.html`.
- Edit **only** `styles.css`.
- Use a media query breakpoint at **800px**.
- Use Flexbox or Grid (your choice) — just be consistent and readable.

## Requirements

### Mobile (viewport < 800px)

- Everything is stacked (single column): header → nav → main → aside → footer.

### Desktop (viewport ≥ 800px)

- Header and footer span full width.
- The middle becomes a 2-column layout:
  - Left column: main content (wide)
  - Right column: aside (narrow)
- Nav sits above the 2 columns (full width), below the header.

## Visual targets

Open the target SVGs next to your page and match the layout.
