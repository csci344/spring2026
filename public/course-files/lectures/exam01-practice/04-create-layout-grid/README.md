# Exercise 04 — Create this layout (Grid)

## Goal

Recreate the layout shown in `target.svg` using **CSS Grid**.

## Rules

- Do **not** edit `index.html`.
- Edit **only** `styles.css`.
- Use CSS Grid (e.g., `display: grid`, `grid-template-columns`, `grid-template-areas`, `gap`).
- You may **not** use Flexbox for the main page layout (fine inside small components, but don’t solve the whole thing with flex).

## Requirements

- The page has 5 regions:
  - `header` (top, full width)
  - `nav` (left column)
  - `main` (center column)
  - `aside` (right column)
  - `footer` (bottom, full width)
- There is consistent spacing (gap) between regions.

## Visual target

Open `target.svg` next to your page and match the layout.
