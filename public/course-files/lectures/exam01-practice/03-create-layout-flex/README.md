# Exercise 03 — Create this layout (Flexbox)

## Goal

Recreate the layout shown in `target.svg` using **Flexbox**.

## Rules

- Do **not** edit `index.html`.
- Edit **only** `styles.css`.
- Use Flexbox (e.g., `display: flex`, `justify-content`, `align-items`, `gap`, `flex`).
- You may **not** use CSS Grid for this exercise.

## Requirements

- The header contains:
  - The “logo” block on the left
  - The navigation on the right (3 links in a row)
- The main area has 2 columns:
  - A sidebar on the left (fixed-ish width)
  - Content on the right (fills remaining space)
- Inside the content area, there is a row of 3 cards with equal spacing.

## Visual target

Open `target.svg` next to your page and match the layout.
