# Tutorial 5 Solutions

This folder contains the complete solutions for Tutorial 5 exercises.

## Files

- **01-theme-switcher-solution.js** - Solution for the theme switcher exercise
- **02-hamburger-menu-solution.js** - Solution for the hamburger menu exercise  
- **03-carousel-solution.js** - Solution for the carousel exercise (with comments)
- **04-todo-list-solution.js** - Solution for the todo list exercise

## How to Use

1. Copy the solution code into the corresponding `index.js` file in each exercise folder
2. Test that it works correctly
3. Try to understand how each solution works before looking at it

## Notes

- The theme switcher solution includes event listeners for all buttons
- The hamburger menu solution uses `classList.toggle()` to add/remove the active class
- The carousel solution includes detailed comments explaining each part
- The todo list solution uses `insertAdjacentHTML('beforeend', string)` to dynamically add list items
